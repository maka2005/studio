## Домен (купить позже)

- [ ] Купить `servio.kz` (при желании также `renvio.kz` для переадресации).

- [ ] В Supabase → Authentication → URL Configuration добавить новый Site URL и Redirect URLs (`https://servio.kz/**`), иначе вход владельца и восстановление пароля будут уводить на старый адрес.
- [ ] Заменить домен во всех захардкоженных местах:
  - `src/marketing/config/site.ts` → `SITE.url`
  - `scripts/prerender-marketing.mjs` → `const site`
  - `index.html` → canonical и `hreflang`
  - `public/sitemap.xml` → все `<loc>`
  - `vercel.json` → при необходимости обновить rewrites/headers
- [ ] Проверить после переезда: `curl -I https://servio.kz/offer` → 200, каноникал и hreflang указывают на новый домен, `/api/health` отвечает JSON, CSP в режиме enforce.
