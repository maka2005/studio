# Что реально проверено

Среда: Node 22, без сети, без pnpm, Postgres, Deno, браузера.

## Выполнено и пройдено
- `node scripts/tenant.mjs validate|new|build|sql graphite`: работают (проверка на валидной, новой и несуществующей студии).
- `node --test supabase/functions/assistant/router.test.ts`: 8 из 8. Проверено: клиентский scope не получает инструменты владельца и их вызов не исполняется; инструмент выполняется до ответа; JSON-fallback при игнорировании tool_choice и при HTTP 400; HTTP 500 не маскируется; отбраковка чужих и невалидных intent; ограниченный цикл.
